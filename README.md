# MCV C6 2026 - Team 3

## Project Overview

This repository contains the work for the Computer Vision course (C6) at MCV 2026 of Team 3.

### Week 1: Background Subtraction and Object Detection

Background modeling and foreground detection using various algorithms (Gaussian models, MOG, MOG2, LSBP, SubSense, LOBSTER). Object detection from generated masks.

**[See Week1 README for detailed information](Week1/README.md)**

### Week 2: YOLO Detection and Multi-Object Tracking

Object detection using YOLO models and multi-object tracking with different trackers (ByteTrack, IOU, OCSORT, SORT).

**[See Week2 README for detailed information](Week2/README.md)**

### Week 3: Optical Flow and Flow-Guided Multi-Object Tracking

Optical flow estimation with multiple methods (PyFlow, GMFlow, FlowFormer++, NeuFlow v2) and multi-object tracking enhanced with optical flow propagation (Flow-IOU, SORT+Flow, ByteTrack+Flow).

**[See Week3 README for detailed information](Week3/README.md)**
